## AI Assistant Usage
 - We have used LLMs and Agentic AI to speed up development offloading redundant tasks such as generating boilerplate, documentation, compilation scripts, writing scripts for testing, shell scripts, generating plots and plots analysis, 
 - We have used LLMs to ocassionally help with debugging and understanding difficult concepts, and also help analyze flaws in our logic and architecture , in no instance did we use AI without developing our own logic and architecting our solution.
 - A good example of how we have used AI is in setting up files like `benchmark.py` or `tests/*/test.py` and other such files in the Compiler Pass Approach. 
 - For core files relating to the project, AI was used to a minimal extent such as for inline completions to speed up syntax writing and documenting the thoughts cleanly, and ocassionally prompted to rewrite certain code in a certain way, in a definitive manner without relying on the LLM to solve problems for us.

    - harness.py - Helper module for compiling, running - generated with the help of AI by prompting ourselves, so as to abstract for potential future use as well.
    - tests - Scripts (test.py) were autogenerated, ideas for tests were developed ourselves and implemented assisted with AI
    - benchmark CUDA programs - Some were provided by TA as mentioned above, remaining were written ourselves to test out various aspects of the solution
